Sawdal's Ender Dragon Overhaul (NeoForge 1.21.1)
=======================================

Makes the first Ender Dragon fight a three-headed, three-phase boss battle, built from
`ender_dragon_requirements.md` (v1.2) in the project docs.

Build and run
-------------
- Minecraft 1.21.1, NeoForge 21.1.252, Java 21.
- In IntelliJ: reload Gradle, then run the `runClient` configuration (or `gradlew runClient`).
- Build a jar with `gradlew build` (output in `build/libs`). Install it on the server **and** every client.
- Requires **GeckoLib 4.9.3+** on both sides. The dev jar is in `libs/`; players need the GeckoLib mod installed too.
- Spell-effect art is generated by `tools/gen_effect_assets.py` (models, animations, textures). Edit and rerun it to restyle the effects.

What it does
------------
| System | Summary |
|---|---|
| Explosion immunity | Beds, TNT, anchors and player-placed crystals do nothing to the dragon (ward ripple + chime). Pillar crystals still hurt it. |
| Phases and heads | 3 heads = phase 1, the fireball head falls at 66%, the lightning head at 33%. Each loss plays a roar, title, bossbar change, harmless flash, sigil and a pause in which the dragon hangs still and cannot be damaged. Heads regrow after a 2-minute lock if crystals heal the dragon back above the threshold. |
| Head attacks | 26 flight maneuvers, chained almost back to back (`maneuvers.pause_seconds`): breath runs (single, double, triple, cross), breath ring, spiral and carpet, fire strafe, fire trail, dive barrage, meteor dive, hover volley, fire circle strafe, fire rain, thunder run, lightning ladder, storm circle, lightning ring trap, combos (breath+fire, breath+thunder, circle barrage, fire+thunder dive, trinity), and perch maneuvers (breath nova, inferno, storm) every few maneuvers (`perch_every`). Passes home in on and lead the target. Extra damage: `maneuvers.damage_multiplier`. |
| Body attacks | Wing gust and edge-aware knockback shockwave (jump to dodge), only while perched (`push_attacks_perched_only`); the perch maneuvers end with one. Feint perches. |
| Crystals | Pulsing void-violet healing beam. One helix crown per pillar in the phase color: wound tight while the crystal lives, shattering into drifting rune fragments under a floating broken halo when it is destroyed (the fragments gather and tremble when it is next to return), and snapping back together while it is summoned; smooth blends between. Pillar crystals use a rune-glass skin in the phase color (player-placed crystals stay vanilla). FIFO queue, one back per minute, 2/3 and 1/3 waves at the thresholds, telegraphed summoning circles, damage resistance while any are alive. |
| Pressure | Soft enrage after 10 minutes, golden apple / healing potion cooldowns, lowest-health targeting, ender pearls fizzle in phase 2. |
| Lockdown | 60 s grace period, then the End is sealed both ways until the dragon dies. Stronghold portals near players are found automatically and get a rune seal and glyph cage; anyone stepping in is thrown back. |
| Wipe recovery | If everyone dies, crystals return, the dragon heals at double speed with the End kept loaded, and the End stays sealed for at least 5 minutes. |
| Finale | Light beams, shockwave ring, collapsing sigil, title card and fanfare, timed to vanilla's death animation (egg and portal still spawn). |

Operator commands (permission level 2)
--------------------------------------
- `/dragonfight status` - state, phase, heads and locks, crystal queue, timers
- `/dragonfight start` - start the fight (grace period)
- `/dragonfight skipgrace` - seal the End now
- `/dragonfight health <percent>` - set dragon health
- `/dragonfight attack <maneuver|gust|shockwave>` - run a maneuver (e.g. `breath_run`, `meteor_dive`, `perch_storm`) or body attack now; tab-complete lists them
- `/dragonfight wipe` / `/dragonfight finishrecovery` - test the recovery flow
- `/dragonfight kill` - start the death sequence
- `/dragonfight unseal` - emergency reset to DORMANT
- `/dragonfight reset` - fresh dragon, three heads, all crystals; also enables the overhaul on a respawned dragon

Config
------
- Server: `<world>/serverconfig/dragonoverhaul-server.toml` - every tunable number (health, thresholds, cooldowns, damage, multipliers, enrage, pearl mode, particle density, ...).
- Client: `config/dragonoverhaul-client.toml` - `reduce_flashing` (no phase 2 flicker) and `reduced_effects`. `tools/preview_pillar_designs.py` renders the helix crown in each state and phase color.
- Phase colors: void violet (phase 1), orange crimson (phase 2), sky blue (phase 3), each around a white-hot line.

Known limits
------------
- The two extra heads have their own hitboxes (full head damage while alive, body damage on the stump once severed).
- The phase 3 size increase is visual only; hitboxes stay vanilla size.
- Phase 2 cloak: the dragon alternates long visible / invisible stretches (`phase2_visible_seconds`, `phase2_invisible_seconds`).
- Sounds are vanilla sounds (no custom sound files yet), and there is no phase music.
- A potion cooldown applies to every potion of that bottle type (vanilla cooldowns are per item).
- Respawned dragons (summoned with end crystals) get the full overhaul too; set `apply_to_respawned_dragons = false` to keep them vanilla.
